# Home EMI Calculator

A Python-based Home EMI (Equated Monthly Installment) calculator.

## Usage

```bash
python emi_calculator.py
```

## Setup

```bash
python -m pip install -r requirements.txt
```

> **Note:** Use `python -m pip` instead of bare `pip` to avoid
> `"pip: The term 'pip' is not recognized"` errors on Windows PowerShell.

## Running Tests

```bash
python -m unittest discover -s . -p "test_*.py" -v
```
